# قالب‌های پیامکی SMS.ir — راه‌اندازی

## چرا این کار لازم است

پیامک کد ورود (OTP) همیشه درست کار می‌کرد چون از **API قالب‌محور (Verify)** ارسال
می‌شود — این API روی خط اختصاصی سایت سوار نیست؛ SMS.ir خودش آن را از استخر خطوط
خدماتی‌اش می‌فرستد. مستندات رسمی SMS.ir هم صریحاً می‌گوید این روش برای
«اطلاع‌رسانی وضعیت سفارشات» هم ساخته شده، نه فقط کد ورود.

بقیهٔ پیامک‌ها (پیش‌فاکتور، سفارش، هشدار قیمت) روی **ارسال متن آزاد** بودند که
به نوع و اعتبار خط تنظیم‌شده حساس است — دقیقاً همان چیزی که باعث قطعی اخیر شد.

**راه‌حل:** هر پیامکِ ساخت‌یافته را هم به همان روش قالب‌محور OTP منتقل می‌کنیم.
کد این کار از قبل آماده و deploy شده — فقط باید قالب‌ها را در پنل SMS.ir بسازید
و شناسهٔ هرکدام را به من بدهید.

## نحوهٔ کار (چیزی که در کد پیاده شده)

هر پیامک یک متغیر محیطی اختیاری دارد. **تا وقتی آن را تنظیم نکنید، همان روش
قبلی (ارسال متن آزاد روی خط) دقیقاً مثل الان کار می‌کند — هیچ‌چیز خراب نمی‌شود.**
به محض این‌که شناسهٔ قالب را بدهید و من متغیر را تنظیم کنم، همان پیامک بی‌درنگ
(فقط با ری‌استارت، بدون rebuild) به روش قالب‌محور سوئیچ می‌کند.

## مراحل ساخت هر قالب در پنل SMS.ir

۱. وارد پنل کاربری SMS.ir شوید.
۲. مسیر: **برنامه‌نویسان ← ارسال سریع (Quick Send)** ← ایجاد قالب جدید.
۳. متن قالب را دقیقاً همان‌طور که پایین آمده paste کنید — متغیرها باید بین
   دو علامت `#` باشند و **نام هر متغیر باید حرف‌به‌حرف با ستون «پارامتر» زیر
   یکی باشد** (بزرگ/کوچک بودن حروف هم مهم است).
۴. تأیید قالب توسط SMS.ir انجام می‌شود (معمولاً چند دقیقه تا چند ساعت).
۵. بعد از تأیید، عدد **شناسهٔ قالب (Template ID)** را از پنل بردارید و برای من
   بفرستید — نام هرکدام را هم بگویید تا در جای درست بگذارم.

## قالب‌ها (به ترتیب اولویت)

### ۱. صدور پیش‌فاکتور — `SMSIR_TEMPLATE_ID_PROFORMA_ISSUED`
مهم‌ترین قالب؛ لحظهٔ صدور قیمت نهایی برای مشتری.

```
آهن‌تایم: پیش‌فاکتور شما صادر شد. مبلغ: #AMOUNT# تومان. اعتبار تا #EXPIRY# ساعت ۱۱:۰۰. مشاهده: ahantime.com/proforma/#REF#
```

| پارامتر | مثال مقدار |
|---|---|
| AMOUNT | ۷۸۲٬۶۵۰ |
| EXPIRY | ۱۴۰۵/۰۴/۱۳ |
| REF | PF-14050411-0001-ABCDEF |

### ۲. ثبت درخواست (بدون قیمت) — `SMSIR_TEMPLATE_ID_PROFORMA_REQUEST`
وقتی مشتری فقط درخواست می‌فرستد و هنوز قیمتی صادر نشده.

```
آهن‌تایم: درخواست شما ثبت شد. کارشناسان به‌زودی تماس می‌گیرند. مشاهده: ahantime.com/proforma/#REF#
```

| پارامتر | مثال مقدار |
|---|---|
| REF | PF-14050411-0002-ABCDEF |

### ۳. تأیید سفارش — `SMSIR_TEMPLATE_ID_ORDER_CONFIRMED`
لحظهٔ تبدیل سرنخ به سفارش (فقط همین یک لحظه — مراحل بعدی حمل، قالب‌های زیر را دارند).

```
آهن‌تایم: سفارش شما ثبت شد. کد رهگیری: #REF#. پیگیری در ahantime.com/track
```

| پارامتر | مثال مقدار |
|---|---|
| REF | OR-14050411-0001-ABCDEF |

### ۳-الف. پیشرفت وضعیت سفارش — `SMSIR_TEMPLATE_ID_ORDER_STATUS`
هر بار وضعیت سفارش به «تأییدشده»، «بارگیری» یا «در حال حمل» می‌رود (به‌جز خودِ
«تحویل» که قالب جدا و گرم‌تری دارد — پایین‌تر).

```
آهن‌تایم: وضعیت سفارش #REF# به «#STAGE#» تغییر کرد. پیگیری: ahantime.com/track
```

| پارامتر | مثال مقدار |
|---|---|
| REF | OR-14050411-0001-ABCDEF |
| STAGE | بارگیری |

### ۳-ب. تحویل سفارش — `SMSIR_TEMPLATE_ID_ORDER_DELIVERED`
مهم‌ترین لحظهٔ حمل از دید مشتری؛ قالب جدا با لحن قدردانی، نه فقط «وضعیت تغییر کرد».

```
آهن‌تایم: سفارش #REF# با موفقیت تحویل داده شد. از خرید شما سپاسگزاریم.
```

| پارامتر | مثال مقدار |
|---|---|
| REF | OR-14050411-0001-ABCDEF |

### ۳-ج. ثبت کد رهگیری — `SMSIR_TEMPLATE_ID_ORDER_SHIPPING`
لحظه‌ای که کارشناس شمارهٔ رهگیری واقعی را وارد می‌کند (نه فقط نام شرکت حمل به‌تنهایی).

```
آهن‌تایم: سفارش #REF# با #CARRIER# ارسال شد. کد رهگیری: #TRACKING#
```

| پارامتر | مثال مقدار |
|---|---|
| REF | OR-14050411-0001-ABCDEF |
| CARRIER | باربری تیپاکس |
| TRACKING | TIP-998877 |

### ۳-د. لغو سفارش — `SMSIR_TEMPLATE_ID_ORDER_CANCELLED`
وقتی سفارش لغو یا آرشیو می‌شود.

```
آهن‌تایم: سفارش #REF# لغو شد. برای اطلاعات بیشتر با پشتیبانی تماس بگیرید.
```

| پارامتر | مثال مقدار |
|---|---|
| REF | OR-14050411-0001-ABCDEF |

### ۴. هشدار قیمت — `SMSIR_TEMPLATE_ID_PRICE_ALERT`
وقتی قیمت کالا/شاخص به آستانه‌ای که کاربر تعیین کرده می‌رسد.

```
آهن‌تایم: #LABEL# به #VALUE# تومان رسید (هدف شما: #DIR# #THRESHOLD#). ahantime.com/market
```

| پارامتر | مثال مقدار |
|---|---|
| LABEL | میلگرد ۱۴ آجدار |
| VALUE | ۳۵٬۲۰۰ |
| DIR | زیر (یا: بالای) |
| THRESHOLD | ۳۶٬۰۰۰ |

### ۵. یادآوری انقضای پیش‌فاکتور — `SMSIR_TEMPLATE_ID_PROFORMA_REMINDER`
یادآوری خودکار ۲۴ ساعت قبل از انقضا.

```
آهن‌تایم: پیش‌فاکتور #AMOUNT# تومانی شما تا #EXPIRY# معتبر است. برای نهایی‌کردن: ahantime.com/proforma/#REF#
```

| پارامتر | مثال مقدار |
|---|---|
| AMOUNT | ۷۸۲٬۶۵۰ |
| EXPIRY | ۱۴۰۵/۰۴/۱۳ |
| REF | PF-14050411-0001-ABCDEF |

### ۶. یادآوری تماس (داخلی، اختیاری) — `SMSIR_TEMPLATE_ID_CALLBACK_REMINDER`
این یکی برای **خود کارشناس** فرستاده می‌شود، نه مشتری — اولویتش پایین‌تر است
و می‌توانید فعلاً از آن صرف‌نظر کنید؛ تا وقتی قالبش نباشد، همان پیامک قبلی
(با نام و شمارهٔ مشتری) روی خط ادامه می‌یابد.

```
آهن‌تایم: یادآوری تماس برای سرنخ #REF#. پنل: panel.ahantime.com/desk
```

| پارامتر | مثال مقدار |
|---|---|
| REF | LD-14050411-0003-ABCDEF |

## بعد از ساخت هر قالب

فقط شناسهٔ عددی (Template ID) هرکدام را برایم بفرستید — من متغیرهای محیطی را
روی سرور تنظیم و سرویس را ری‌استارت می‌کنم (rebuild لازم نیست). می‌توانید
قالب‌ها را یکی‌یکی بفرستید؛ هر کدام که برسد همان لحظه فعال می‌شود، بدون تأثیر
روی بقیه.

## نکتهٔ محدودیت مقدار پارامتر

SMS.ir طول هر مقدار پارامتر را حداکثر ۲۵ کاراکتر می‌پذیرد. کد از قبل هر مقدار
طولانی‌تر را با `…` کوتاه می‌کند (`truncateParam` در `smsir.ts`) تا ارسال هیچ‌وقت
به همین دلیل رد نشود — رفتار مطلوب همین است، نیازی به دخالت نیست.
