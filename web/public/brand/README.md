# برند آهن‌تایم — فایل‌های لوگو

## لوگوی اصلی — `ahantime-logo.png`

**تنها فایلی که باید عوض کنی همینه.** هدر سایت، نوار بالای پنل ادمین و سربرگ
پیش‌فاکتور همه از `web/public/brand/ahantime-logo.png` می‌خونن و اندازه/نسبت
تصویر رو خودِ کد از روی فایل حساب می‌کنه — هر ابعادی باشه به‌هم نمی‌ریزه.

- فرمت: PNG با پس‌زمینهٔ شفاف (ترجیحاً حداقل ۵۱۲ پیکسل ارتفاع).
- جایگزینی از GitHub: مسیر `web/public/brand/` → Add file → Upload files →
  فایل رو با همین نام دقیق `ahantime-logo.png` آپلود کن تا جایگزین بشه.
- بعد از merge شدن، باید ایمیج جدید build و دیپلوی بشه تا روی سایت بیاد.

## فاوآیکون‌ها

`icon-32/192/512.png` و `apple-icon.png` از روی لوگوی اصلی ساخته می‌شن؛ بعد از
عوض‌کردن لوگو باید از روی فایل جدید دوباره تولید بشن (مربع، با کمی حاشیه برای
آیکون اپل روی زمینهٔ سفید).
