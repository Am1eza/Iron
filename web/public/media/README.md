# رسانه‌های صفحهٔ اصلی

## ویدیوی هیرو — `hero.mp4`

فایلی که اینجا با همین نام دقیق `hero.mp4` قرار بگیره، آماده‌ست تا جای تابلوی
قیمت زنده در صفحهٔ اصلی نمایش داده شود — بی‌صدا، لوپ، اتوپلی.

- فرمت: MP4 (H.264).
- حجم: ترجیحاً چند مگابایت، نه چند ده مگابایت — این ویدیو روی موبایل هم
  اتوپلی می‌شود و روی سرعت بارگذاری صفحهٔ اصلی اثر مستقیم دارد.
- جایگزینی از GitHub: مسیر `web/public/media/` → Add file → Upload files →
  فایل را با همین نام دقیق `hero.mp4` آپلود کن.
- بعد از merge شدن، باید ایمیج جدید build و دیپلوی شود تا فایل روی سایت
  بیاید — و در `/admin/settings` → «ویدیوی صفحهٔ اصلی» → مسیر ویدیو باید
  `/media/hero.mp4` ثبت و ذخیره شود تا واقعاً نمایش داده شود.
