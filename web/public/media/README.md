# رسانه‌های صفحهٔ اصلی

## ویدیوی هیرو

فقط `hero.mp4` لازم است تا کار کند — همیشه، به‌عنوان نسخهٔ تضمینی، همین یک
فایل کافی‌ست. فایل‌های زیر **اختیاری**اند و فقط برای سبک‌ترشدن و سریع‌ترشدن
سایت اضافه شده‌اند؛ اگر نباشند مرورگر بی‌سروصدا از `hero.mp4` استفاده می‌کند:

| فایل | برای چی |
|---|---|
| `hero.mp4` | **الزامی.** نسخهٔ اصلی، H.264، همه‌جا کار می‌کند. |
| `hero.webm` | نسخهٔ سبک‌تر (VP9) برای مرورگرهایی که پشتیبانی می‌کنند. |
| `hero-mobile.mp4` | نسخهٔ کوچک‌تر برای تبلت (عرض صفحه تا ۱۰۲۳ پیکسل). |
| `hero-mobile.webm` | همان، با فرمت سبک‌تر. |
| `hero-poster.webp` | یک فریم ثابت که تا آماده‌شدن ویدیو نمایش داده می‌شود. |

نکتهٔ مهم: **زیر ۷۶۸ پیکسل عرض صفحه (موبایل)، ویدیو اصلاً پخش نمی‌شود** —
همان تابلوی قیمت زنده نمایش داده می‌شود. همچنین برای بازدیدکننده‌هایی که
«کاهش انیمیشن» را در گوشی/مرورگرشان فعال کرده‌اند یا اینترنتشان کند/محدود
تشخیص داده شود. یعنی نگرانی حجم برای موبایل اصلاً موضوعیت ندارد — این
فایل‌ها فقط برای دسکتاپ و تبلت استفاده می‌شوند.

### جایگزینی ویدیو

ساده‌ترین راه: فقط `hero.mp4` جدید را در GitHub، مسیر `web/public/media/` →
Add file → Upload files، با همین نام دقیق آپلود کن. کار می‌کند، ولی حجمش را
از تلگرام/گوشی مستقیم export نکن — قبلش از Claude بخواه که فایلت را بررسی و
اگر لازم بود، فشرده‌سازی و بقیهٔ نسخه‌های اختیاری بالا را هم برایت بسازد
(صدا هم اگر داشته باشد حذف می‌شود — چون ویدیو همیشه بی‌صداست، صدا فقط حجم
اضافه است).

بعد از merge شدن، باید ایمیج جدید build و دیپلوی شود تا فایل روی سایت بیاید
— و اگر مسیر عوض شده، در `/admin/settings` → «ویدیوی صفحهٔ اصلی» → مسیر
ویدیو باید ثبت و ذخیره شود.
