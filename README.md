# آهن‌تایم — Ahantime

بازار آهن و فولاد با قیمت‌های کاتالوگ، مشاور هوش مصنوعی و فروش با پیگیری انسانی.

> اول مشورت، بعد خرید.

این مخزن شامل برنامهٔ عملیاتی Next.js، بک‌اند PostgreSQL، پنل مدیریت، ابزارهای استقرار و مشخصات محصول و طراحی است. مسیر فروش از درخواست و پیش‌فاکتور به تماس کارشناس می‌رسد؛ پرداخت آنلاین ندارد.

## قواعد محصول

- رابط فارسی، RTL، تاریخ جلالی و مبلغ به تومان.
- ورود با شمارهٔ موبایل و OTP؛ ارائه‌دهندهٔ پیامک SMS.ir است.
- قیمت‌ها و مبنای محاسبه از داده و قواعد سمت سرور می‌آیند؛ مدل هوش مصنوعی مرجع تولید قیمت نیست.
- ثبت دستی قیمت و زیرسیستم همگام‌سازی منابع در کد وجود دارند؛ وضعیت اجرایی هر منبع باید در پنل و تنظیمات همان محیط بررسی شود.
- مشاور از relay سمت سرور با تنظیمات `AI_*` استفاده می‌کند؛ جزئیات در [راهنمای AI](web/AI.md).
- CSS Modules و توکن‌های طراحی؛ فونت‌ها محلی هستند و UI kit یا CDN خارجی استفاده نمی‌شود.

## ساختار

| مسیر                      | محتوا                                              |
| ------------------------- | -------------------------------------------------- |
| `web/`                    | رابط، API، احراز هویت، پایگاه داده، jobها و تست‌ها |
| `product/`, `foundation/` | نیازمندی‌ها، تصمیم‌ها، برنامهٔ محصول و شاخص‌ها     |
| `design/`, `brand/`       | سیستم طراحی، توکن‌ها و هویت برند                   |
| `docs/`                   | راهنماهای عملیاتی، نقشهٔ راه و سوابق بررسی         |
| `ops/`                    | ابزارهای عملیاتی و پشتیبان‌گیری                    |

مشخصات محصول بیانگر قصد طراحی‌اند؛ راهنماهای فنی باید با کد تطبیق داده شوند. گزارش‌های مقطعی در [آرشیو موضوعی](docs/README.md#historical-reports) نگهداری می‌شوند و گواه وضعیت فعلی تولید نیستند.
